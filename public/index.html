🌀 Vibe Check API

This is the backend for the Vibe Check hackathon app — there's no UI here, just the API.

  • GET /api/options — palette, emoji, energy levels, moods
  • GET /api/vibes / POST /api/vibes — the wall
  • GET /api/pulse — room energy, mood, colour board, hype leaders

Full contract: api/vibe-check.openapi.yaml in the repo.
